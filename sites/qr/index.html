Why these codes don't die

  • No middleman linkMany QR sites encode their own short link and forward people to yours. If their trial ends or they shut down, every printed code breaks. Ours encodes your link itself.
  • No scan trackingA scan goes from the phone straight to your link. We never see it, so we can't count it or sell it.
  • Your Wi-Fi password stays hereThe page's security policy sets connect-src 'none', so your browser won't let it send what you type anywhere.
  • Test-scanned for youBefore you download, the page reads the code back with a separate open-source scanner and checks it matches what you typed.

Questions

Will my QR code ever expire?

No. The code holds your link or text directly, so it works for as long as the thing it points to exists. If you change your website address later, you'll need a new code, because nothing sits in between to redirect it.

Can I see how many people scanned it?

Not from the code. Counting scans needs a middleman link, which is the thing that lets other services turn codes off. If you want numbers, add a tracking tag to your own link (for example ?utm_source=flyer) and check your website's analytics.

PNG or SVG?

PNG works everywhere: docs, slides, social posts. SVG stays sharp at any size, so printers and designers usually want it for signs and packaging.

Why won't my colored code scan?

Scanners need a dark code on a light background with strong contrast. The page warns you when your colors are risky. A light code on a dark background works on many new phones and fails on plenty of older ones.

What does "damage tolerance" do?

Higher settings add spare data so the code still scans when part of it is scratched, folded or covered. The pattern gets denser, so for short links on a screen, Medium is plenty.
